# 🚀 Постироничные скрипты для Hyprland

Набор кастомных Bash-скриптов для автоматизации и кастомизации графического окружения Hyprland на Arch Linux. Главная фишка — **заставка загрузки Windows 11**, которая проигрывается сразу после разблокировки экрана/входа в систему.

---

## 📺 Скрипт автозапуска и заставки (`boot_intro.sh`)

Скрипт убивает зависшие процессы старой панели, запускает утилиты обхода блокировок (`zapret`) и сети в изолированном фоне, после чего проигрывает видео на весь экран и бесшовно накатывает обои и `waybar`.

### 📦 Зависимости

Перед запуском скрипта убедись, что в системе установлены все необходимые пакеты. Установи их через `pacman`:

```bash
sudo pacman -S --needed mpv swaybg waybar network-manager-applet
```

### 🗂️ Подготовка файлов

Скрипт использует автоматическое определение домашней директории (`$HOME`), поэтому тебе нужно просто разложить файлы по следующим путям:
1. Видео-заставку (например, `win11bootanimation.mp4`) положи в папку: `~/Videos/`
2. Твои финальные обои (например, `linux.png`) положи в папку: `~/Pictures/`
3. Утилита `zapret` должна находиться по пути: `~/zapret-discord-youtube-linux/`

### ⚙️ Как настроить автозапуск в Hyprland

Чтобы скрипт срабатывал автоматически при каждом запуске графического окружения, добавь следующую строку в свой файл конфигурации `~/.config/hypr/hyprland.conf`:

```ini
exec-once = ~/.config/hypr/boot_intro.sh
```

Не забудь сделать сам файл скрипта исполняемым в терминале:
```bash
chmod +x ~/.config/hypr/boot_intro.sh
```
